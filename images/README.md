# Images for OSCA Nature Travel for Safari

The pictures currently in this folder are **simple generated placeholder illustrations**, not real photographs.
Replace each one with a real photo that the company owns or has permission to use.

## How to replace an image
1. Prepare your photo as a **.jpg** file.
2. Give it the **exact same file name** as the placeholder (see the table).
3. Put it in this `images` folder, replacing the old file.
4. Upload the change to GitHub. Cloudflare Pages updates the site automatically.

If you want to use a different file name or a .png/.webp file, open `index.html` and change the matching `src="images/..."` text.

## Tips
- Keep each image under about 300 KB so the site loads quickly on mobile data (free tools like squoosh.app can shrink photos).
- Use only photos you have the right to publish.
- If you change an image, also update its `alt="..."` description in `index.html` so it describes the new photo.
